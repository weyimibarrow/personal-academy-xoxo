# Smarty Pants (working title)

A web app that helps people reach **genuine mastery** of any subject by using AI as a
**curriculum architect and registrar** — not a tutor, not a chatbot.

## Workflow

- `main` — stable/default branch. Changes land here via reviewed Pull Requests.
- Feature branches (e.g. `claude-architecture-roadmap-smarty-pants-123`) — where draft
  work and planning docs live before being merged to `main`.

The product spec, architecture, and full roadmap arrive via the first PR into `main`.
